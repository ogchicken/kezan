# Price addons are optional and called through their public APIs

Kezan reads auction prices from Auctionator and TradeSkillMaster only through their documented public APIs (`Auctionator.API.v1.*` and `TSM_API.*`), lists both as `## OptionalDeps` and works without either, falling back to vendor prices. No code from either addon is copied, vendored or adapted into this repository. We chose this because both addons are All Rights Reserved while Kezan is MIT, because Auctionator's author commits to keeping the v1 API stable while internals change between releases, and because many players run only one of the two. Showing TSM prices also follows TSM's public data terms: credit and a link, no bulk republishing, no implied endorsement. Reading another addon's saved variables or internals would mean superseding this decision.
